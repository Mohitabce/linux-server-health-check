# Linux Server Health Check

A Bash script to monitor basic Linux server health.

## Features

- CPU usage check
- Memory usage check
- Disk usage check
- System uptime
- Running services check
- Network connectivity check

## Requirements

- Linux operating system
- Bash shell

## Usage

Make the script executable:

chmod +x health-check.sh

Run the script:

./health-check.sh
